Welcome. This site is a worked example of Hugo with the Docsy theme. The
left-hand sidebar is built from the folder tree under `content/`: each folder
with an `_index.md` is a section, and each other `.md` file is a page.

{{% alert title="How to read this example" color="info" %}}
Open each section in the sidebar. Every page explains the feature it
demonstrates, and the page's source file is named in its first paragraph.
{{% /alert %}}

Sections in this example:

- **Getting Started** - what Hugo and Docsy are, and how pages are created.
- **Navigation** - how the sidebar, ordering, titles and nesting work.
- **Content Examples** - shortcodes and formatting you can reuse.
- **Reference** - a deeper nesting example (three levels).
