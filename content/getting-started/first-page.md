---
title: Your First Page
weight: 2
description: Adding a page is just adding a Markdown file.
---

Create a file in `content/`, give it front matter, and it appears in the
sidebar, ordered by `weight`.

```markdown
---
title: My Page
weight: 5
description: Shown in the parent section's list.
---

Page content in Markdown.
```

{{% alert title="Tip" %}}
Docsy shortcodes like this alert work in any page.
{{% /alert %}}
